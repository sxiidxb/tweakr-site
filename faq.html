FAQ & Why Trust Us

Straight answers, no marketing fog.

Why trust us

Native Windows APIs only. Tweakr talks to your PC through the same official channels Windows itself uses — standard system calls and PowerShell commands. There are no hidden backdoors, no bundled miners, no silent uploads. Every privileged action shows you a preview and waits for your confirm.

Antivirus false positives, explained. Optimizer and scripting tools sometimes trip Windows Defender because they touch startup entries, the registry, and run scripts — the exact behaviors malware also uses. That is a heuristic guess, not a verdict. If Defender flags Tweakr, open Virus & threat protection → Manage settings → Exclusions → Add an exclusion → Folder and add your Tweakr install folder. Downloaded from this site, Tweakr is safe to exclude.

Your secrets stay on your machine. Passwords and keys live in the OS credential store, never in settings files or backups. License checks only ever send your key — nothing else leaves your PC.

What is the difference between Tweakr Grey (Free) and Tweakr Black (Paid)?

Grey is the free everyday optimizer: dashboard, file sorter, cleaner, startup manager, Shield, fixes, and monitor. Black is the $15 one-time power suite with live process control, script inspection, offline repair, a secret vault, network watch, and local AI tooling.

Will tweaking or debloating break my Windows installation or Windows Update?

No. Tweakr only touches safe, reversible settings and always previews changes before applying them. It never removes Windows Update components or core system services. If anything ever feels off, the built-in System Fixes module restores the defaults.

How do I update Tweakr when a new version drops?

Download the new installer from the download page and run it — your settings and license carry over automatically. Watch the changelog page for release notes on every version.

Can I use my Tweakr Black license on multiple computers?

One email owns one license key. If you move to a new PC, just install Tweakr Black there and activate with the same key — and if the old machine blocks you, contact support to unbind it.

I lost my license key. How do I get it back?

Create a free account with the same email you bought with, then open My Licenses — every key on that email is listed there and can be copied back into the app.
